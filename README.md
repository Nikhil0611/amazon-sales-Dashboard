# 📊 Amazon Sales Dashboard | Power BI

An interactive **Amazon Sales Dashboard** built using **Microsoft Power BI** to analyze sales performance, profit, customer behavior, and product categories. This dashboard helps users identify key business insights through interactive charts, KPIs, and filters.

---

## 🚀 Project Overview

The Amazon Sales Dashboard provides a clear view of business performance by visualizing important sales metrics. It enables users to monitor sales trends, compare category performance, and make data-driven decisions.

---

## 📌 Features

- 📈 Sales Performance Analysis
- 💰 Profit Analysis
- 📦 Order Analysis
- 👥 Customer Insights
- 🗂️ Category & Sub-Category Analysis
- 📅 Time-Based Sales Trends
- 🎯 Interactive Filters and Slicers
- 📊 KPI Cards for Quick Insights

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

---

## 📊 Dashboard KPIs

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Top Performing Products
